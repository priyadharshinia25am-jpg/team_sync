1. Purpose
This README explains how to review the Phase 3 evidence for TEAM SYNC.
The selected concept aims to help first-time entrepreneurs and
small-business owners identify potentially relevant approvals,
documents, government departments, and official source links based on
business type and location.

4. Review / replay steps
1. Open P3-E01 and inspect the example approval checklist.
2. Open P3-E02 and inspect the example departments and schemes list.
3. Open P3-E03 and inspect the example comparison table.
4. If a runnable prototype is included, follow its actual setup
   instructions and enter permitted test business profiles.
5. Compare each generated checklist with a manually prepared reference
   checklist based on relevant official government sources.
6. Record profile ID, expected requirements, generated requirements,
   missing items, incorrect items, source-link coverage, and pass/fail
   result.
7. Preserve raw outputs and failed runs. Document any retest
   separately.
If no runnable prototype or raw logs are included, state "Not
available"; do not claim a replay was completed.
5. Test protocol and measurements
The proposed bounded test uses 12 mock business profiles. Compare the
generated checklist against a manually prepared reference checklist.

Record: - Number of profiles tested. - Number of profiles meeting the
original match criterion. - Missing and incorrect requirements. - Number
of listed requirements with relevant official source links. - Test date,
artifact version, reviewer, and exclusions.

Use the original Phase 2 success threshold if it was recorded before
testing. Do not present a newly chosen threshold as an original
criterion. If the original threshold cannot be confirmed, disclose that
limitation.
6. Expected output
For each profile, retain: - Business type and location (mock data
only). - Generated checklist. - Reference checklist and official source
links. - Comparison of matches, missing items, and incorrect items. -
Summary calculations with numerator and denominator. - Any warnings for
unavailable or uncertain information.

No particular match rate or successful result is guaranteed by this
README.
7. Safety, privacy, and limitations
- Use mock profiles unless permission has been obtained for real-user
  testing.
- Do not upload personal, confidential, or sensitive information.
- This concept provides guidance, not legal advice or an official
  government decision.
- Users must verify requirements with relevant official portals or
  authorities.
- Requirements may vary by state, locality, business type, and
  circumstances.
- Mock-ups do not establish legal accuracy, adoption, time saved, or
  production readiness.
- Do not claim government integration or automatic application
  submission unless implemented and evidenced.
